# Contributing

Anyone can submit a Black Friday or Cyber Monday deal for Blender add-ons, 3D assets, or AI 3D tools. Makers are welcome to submit their own offers. Please disclose your affiliation.

## Submit an offer

1. Search the [README](README.md) for the product and vendor domain.
2. [Open a deal submission](../../issues/new?template=submit-deal.yml) or add one row in the matching README table and open a pull request.
3. Use the vendor’s official offer URL and state the discount, code, eligibility, and deadline. For subscriptions, say what the buyer pays after the promotion when the vendor publishes that information.

Use one entry per offer and keep the description factual. Submit the direct vendor URL. Maintainers label the Superhive links that may earn ThreeDee a commission. If the vendor omits an end time, time zone, or other detail, leave it unspecified.

## Correct or archive a deal

If an offer changes or expires early, open an issue or pull request with the official source. Maintainers move expired offers out of the active tables and keep the previous season’s list in the repository history.
